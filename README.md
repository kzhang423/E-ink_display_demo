# E-ink display demo w/ NUCLEO-WB09KE

## <ins>Pin header CN4</ins>

|Pin|WB09KE Pin|Function|
|---|---|---|
|3|PB6|RST|
|5|PB7|DC|
|7|VDD|-|


PIN 3 -> PB6 (RST)

PIN 5 -> PB7 (DC)

PIN 7 -> VDD

PIN 9 -> GND

PIN 11 -> PB3 (SPI3_SCK)

PIN 13 -> PA8 (SPI3_MISO)

PIN 15 -> PA11 (SPI3_MOSI)

PIN 17 -> PA9 (SPI3__NSS)

PIN 19 -> PB14 (BUSY)

PIN 21 -> PB15 (CS)

PIN 30 -> PB5 (PWR)
